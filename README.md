# Proyecto Musical: Hard Rock Old School en Sol Menor (G minor)

Proyecto de composición, arreglos, producción y grabación para una balada / tema de Hard Rock clásico con sonido británico ("old school").

## 🎸 Resumen Técnico Rápido

* **Tonalidad:** Sol menor (G minor / Pentatónica menor de Sol).
* **Tempo:** 80 BPM (4/4).
* **Rango Vocal:** Barítono / Bajo (**D2 – D#4**).
* **Guitarras:**
  * *Pista Izquierda (100% L):* Epiphone Les Paul Pro (Pastilla puente / caoba).
  * *Pista Derecha (100% R):* Hamer Superstrat (Seymour Duncan puente + single coil mástil).
* **Amplificación:** Line 6 Spider V 20 (Modelo Brit 800 / Cab 4x12 Vintage 30 / Greenback).
